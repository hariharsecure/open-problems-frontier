# Every sequence, in one line

A plain-English "what is this counting?" for all **41** sequences this project extended, grouped by
category. Each is a **computed-and-verified candidate extension** — new exact numbers that two
independent programs agreed on, offered as candidates to (not yet accepted by) the OEIS. No famous
problem is solved by any of these.

*"Graph" = dots joined by lines. "Torus" = a grid wrapped into a donut. "Fibonacci / Lucas cubes" =
networks built from binary strings with no two 1s in a row.*

## Matchings — pairing up neighbors

- **A286017** — How many ways to pick non-overlapping neighbor-pairs (a matching) in the Tower-of-Hanoi puzzle graph.
- **A287595** — How many ways to pair up neighbors on an n×n grid so that no more pairs can be added (maximal matchings).
- **A291935** — How many ways to pick non-overlapping neighbor-pairs in a Fibonacci cube.
- **A292017** — How many of the largest-possible pairings (maximum matchings) exist in a Fibonacci cube.
- **A292669** — How many ways to pick non-overlapping neighbor-pairs in a Sierpinski-tetrahedron network.
- **A297480** — How many neighbor-pairings on the Tower-of-Hanoi graph leave no room to add another pair (maximal matchings).
- **A297484** — How many maximal neighbor-pairings exist in the Johnson / triangular graph (dots are pairs drawn from a set).
- **A297485** — How many maximal neighbor-pairings exist on a triangular grid of dots.
- **A297486** — How many maximal neighbor-pairings exist on a grid wrapped into a donut (torus).
- **A297489** — How many maximal neighbor-pairings exist on an n×n king-move chessboard.
- **A297533** — How many largest-possible pairings (maximum matchings) exist in a Sierpinski-tetrahedron network.
- **A297558** — How many largest-possible pairings exist in an Apollonian network (a triangle repeatedly subdivided).
- **A374718** — How many maximal neighbor-pairings exist on the Sierpinski-gasket (triforce) fractal graph.
- **A387566** — How many ways to pick non-overlapping neighbor-pairs in a Lucas cube.

## Dominating sets — covering everything with guards

- **A291920** — How many ways to place guards on a Fibonacci cube so every dot is a guard or sits beside one.
- **A298115** — How many guard-placements on a Fibonacci cube both cover everything and form one connected group.
- **A323516** — Among the smallest guard-placements where even guards need a guard-neighbor, how many cover a Sierpinski tetrahedron (minimum total dominating sets).
- **A347505** — How many ways to place guards covering every dot of the Tower-of-Hanoi graph.
- **A365572** — How many guard-placements cover a Lucas cube when every dot, guards included, needs a guard-neighbor (total dominating).
- **A365580** — How many ways to place guards covering every dot of a Lucas cube.
- **A370573** — How many guard-placements on a Lucas cube cover everything and stay one connected group.

## Spanning trees — wiring up a network with no loops

- **A193134** — How many loop-free ways to wire every dot of a "folded cube" network into one piece.
- **A193135** — How many loop-free wirings connect every dot of a "halved cube" network.
- **A193154** — How many loop-free wirings connect every dot of a triangular graph (dots are pairs, joined when they share an element).
- **A212800** — How many loop-free wirings connect every dot of a grid wrapped into a donut (torus).
- **A288957** — How many loop-free wirings connect every square of an n×n king-move chessboard.
- **A340398** — How many loop-free wirings connect every node of the Bruhat graph, a network built from all the ways to reorder a small deck.

## Domino tilings — covering a board with dominoes

- **A071098** — How many ways to cover a 4n×4n board with n cells punched out using 2×1 dominoes.
- **A071102** — How many ways to tile a diamond board (the "fool's diamond") with dominoes — counted via a determinant shortcut.
- **A071104** — How many ways to tile a variant Aztec-rectangle region with dominoes.
- **A143659** — How many ways to tile an odd square board with its center cell removed using dominoes.
- **A270668** — How many ways to tile odd rectangles with a central hole — a whole table of these counts at once.

## Independent sets & edge covers — picking dots / picking lines

- **A288027** — How many smallest-possible line-sets touch every dot of an n×n grid (minimal edge covers).
- **A288490** — How many ways to pick dots with no two adjacent (equal to the count of vertex covers, their complements) in the Tower-of-Hanoi graph.
- **A297051** — How many line-sets touch every dot (edge covers) of a Fibonacci cube.
- **A297230** — How many edge covers — line-sets touching every dot — exist in a Sierpinski tetrahedron.
- **A321248** — How many no-two-adjacent dot-sets you can't extend (maximal independent sets) exist in an n×n stacked-book graph.
- **A321249** — How many maximal no-two-adjacent dot-sets exist in the Tower-of-Hanoi graph.
- **A321250** — How many maximal no-two-adjacent dot-sets exist on a grid wrapped into a donut (torus).
- **A364745** — How many line-sets touch every dot (edge covers) of a Lucas cube.
- **A378860** — How many smallest-possible line-sets touch every dot of the Sierpinski-gasket (triforce) fractal (minimal edge covers).
