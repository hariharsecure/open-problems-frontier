the 8-Lucas-cube graph Lambda_8 (47 vertices; the Lucas cube uses the same "no two
consecutive 1s" rule as the Fibonacci cube but applied cyclically, i.e. also forbidding
bit0==bit(n-1)==1). Vertices are processed in an independently-chosen linear order (best
of natural/reverse-Cuthill-McKee/BFS orderings by measured width, width=12 for Lambda_8);
per-vertex matched/unmatched status is tracked in a bitmask state (dict: bitmask -> exact
big-integer count), with a vertex forgotten once all its incident edges are resolved. The
program reproduces every previously published b-file term (a(1)..a(7)) exactly before
computing a(8) (feasibility-first gate) -- including correctly resolving the n=1 boundary
case (Lambda_1 = K_1, a single vertex with no edges, since the cyclic
bit0==bit(n-1)==1 condition degenerates to "the lone bit is 1" when n=1) -- and was
implemented TWICE independently in-house (a frozenset-keyed version and a
