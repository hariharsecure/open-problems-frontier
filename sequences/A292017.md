graph Gamma_8 (55 vertices, width=15): the same matched/unmatched frontier machinery as
the plain-matching engine, with each state additionally carrying the number of matched

pass (a two-pass max-then-count folded into a single sweep). Reproduces a(1..7) exactly
before trusting a(8) (feasibility-first). Implemented twice independently in-house

(own graph constructor, own vertex order (width=13), own maximum-matching DP, written by
Codex/GPT-5 with no access to the primary implementation) reproduces the full published
gate and returns the SAME maximum size and the SAME count, digit-for-digit.
